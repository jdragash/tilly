What this lies about. A browser is not iOS.
  • no rubber-band overscroll, and momentum that does not decelerate like iOS
  • no Liquid Glass — the pill and the sheets are flat approximations
  • no Dynamic Type, and no accessibility text sizes at all
  • no real keyboard, no haptics, and a sheet that does not track your thumb
  • no VoiceOver order — half of an editor that a prototype never shows
  • no SF Symbols in the category picker. The eight emoji are an open question, not a proposal: DESIGN.md bans placeholder glyphs, and a fixed icon set may break the same rule
Type scale and spacing are the real Tokens values, so proportions can be trusted. Nothing about feel can be.
