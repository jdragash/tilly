What this prototype lies about

  • No Liquid Glass, rubber-band scrolling or iOS momentum. The glass is a blur.
  • SF Symbols can’t be shown in a web page: I uses glyphs drawn in their manner. L’s pictures are pencil stand-ins, not Image Playground output. G’s drawings are mine, standing in for a set drawn by hand.
  • The emoji keyboard is a small grid, and the symbol picker holds 24 symbols, not 6,900.
  • Rounded type is Nunito standing in for SF Pro Rounded where the browser can’t reach it.
  • Saving always changes the whole bill: “this charge only” isn’t built here. Deleting asks, as the app does. Settings can’t reorder by dragging.
  • No Dynamic Type, VoiceOver or haptics.
